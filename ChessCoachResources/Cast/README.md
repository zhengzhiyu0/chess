# 七位角色语音包 · 听感验收版

每位角色 121 条，覆盖与莉亚相同的 30 类关键事件，共 847 条。正文逐句重写，没有用统一前缀扩充句数，也没有复用莉亚的台词。生成模型为 MiniMax Speech-2.8-HD。

847 条 AAC 总计约 11.48 MiB，合计时长约 35 分 25 秒。与莉亚合计可预览 968 条。

## 试听

用浏览器打开同目录的 `preview.html`。点击角色卡切换，按事件或关键词筛选；“同事件比较八人”包含莉亚作为已确认的基准。“播放下一条”播放当前筛选结果中的下一条。播放器一次只播放一条。

勾选“待调整”会保存在当前浏览器。“导出待调整清单”显示角色、编号和正文，可以直接复制给制作方。

## 文件

- `Audio/<角色>/`：847 个独立 M4A，AAC、单声道、24000Hz、目标 32kbps。
- `Source/<角色>/`：49 个原始合成音频和 49 个逐字时间戳 JSON。包含每人一条独立录音和六段各 20 条的录音。
- `coach_lines.json`：完整台词和每条的角色、事件、说话视角、音频路径、原始片段边界、MiniMax 版本 ID。
- `build-report.json`：数量、体积、总时长、费用估计和自动检查结果。
- 仓库 `scripts/cast_voice_build.json`、`cast_voice_batches.json`、`cast_voice_tasks.json`：音色选择、文本和任务记录，可恢复和追溯；不包含本机绝对路径。
- 仓库 `docs/cast-voice-production.md`：可直接阅读的全套角色文案。

## 后处理和验证

同一角色分段生成后，按逐字时间戳拆分。每句先检查实际字幕文字与设计文字完全一致，再保留字前约 100ms、字后最多约 300ms 的自然余量；相邻句间隔较短时使用间隔中点作为边界，避免带入下一句。结尾只做最多 40ms 淡出，不改变原始音色。

自动检查涵盖每条对应的字幕全文、单词边界、AAC 采样率和声道、完整解码、非静音。语气、读音和最终切分听感仍需人工试听。原始长录音保留，可定位和调整单句边界，无需重新调用模型。

本包已接入普通对弈，莉亚原始录音保持不变。文本中的 `opponent` 指当前角色；`either` 表示可用于双方发生的同类事件。构建时生成的 `web/src/coach-voice/lines.json` 保存最终适用阵营与棋子限制；选择器按这些条件过滤，防止台词中的“你／我”方向错误。

重新处理只读取本地原始文件，不产生 API 费用：

```powershell
.venv\Scripts\python.exe scripts\prepare_cast_audio.py
```

本次工具返回 estimatedCredits 合计为 601 credits。
