## 生成后的筛选标准

保留以下特征：

- 句首有真实起势，句中有自然停顿，句尾不突然降成机器音。
- 情绪先后顺序清楚：惊讶、判断、收束，而不是从头到尾一个音高。
- “后、车、轻子、将杀、牵制、升变”等棋类词汇发音准确。
- 没有额外读出编号、文件名、括号、导演指令或背景音乐。
- 头尾各留约 80～150ms 静音，方便在游戏中衔接。

建议保留最终选中的文本版本和音频版本号，例如 `lia_player_brilliant_01.v2.m4a`，再统一重命名为运行时文件名。
