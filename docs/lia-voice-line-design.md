# 莉亚预烘焙语音设计 v1

制作状态：完整 121 条、30 类事件已生成。实际采用 `Chinese (Mandarin)_Laid_BackGirl` 默认参数；下方的方括号只作设计参考，不提交为情绪参数。试听入口为 `ChessCoachResources/preview.html`。

这份文案只服务于教练「莉亚」。莉亚的声音是精准、克制、优雅，带一点发现漏洞后的轻笑和棋局占优时的从容。她可以尖锐，但不辱骂；她点评的是棋，不给玩家贴标签。

## 使用原则

- 普通落子不播语音。没有命中下面的事件时，只更新气泡文字。
- 每个对手回合最多播一条语音。优先级从高到低为：`mate`、`blunder_into_mate`、`queen_loss`、`brilliant`、`missed_mate`、战术事件、重子吃子、轻子吃子、兵吃子、精准/最佳、开局事件。
- 同一事件组最近 20 条内不重复；同一局连续两次普通事件之间至少间隔 2 个半回合。将杀、错失杀棋和后被吃可以打破间隔。
- 台词正文不写坐标、不写 SAN、不写棋子颜色。具体棋子名称由触发器决定时，优先使用单独录制的「马 / 象 / 车 / 后」版本；第一版也可以直接录通用版本。
- 方括号里的内容是制作方向，不朗读。当前按已确认的默认音色制作，只提交正文和标点，不额外设置情绪或表演参数。
- 每句控制在 8～24 个汉字左右，给停顿和呼吸留空间。不要给每句加固定开头，情绪直接从句子内部开始。

## 触发字段

预烘焙触发器最终需要传入这些信息：

```ts
type LiaVoiceEvent = {
  kind: LiaVoiceKind;
  piece?: 'pawn' | 'knight' | 'bishop' | 'rook' | 'queen';
  side: 'player' | 'lia';
  judgement?: 'book' | 'best' | 'great' | 'brilliant' | 'accurate' | 'inaccuracy' | 'mistake' | 'blunder' | 'miss';
  tactic?: 'fork' | 'pin' | 'discoveredAttack' | 'sacrifice' | 'zwischenzug';
  severity?: 'small' | 'medium' | 'large' | 'decisive';
};
```

`book`、`judgement` 和 `tactic` 必须来自引擎/开局库判断，不能只根据 SAN 猜测。没有这些字段时，使用气泡回退，不播放莉亚语音。

## 开局与准确性

### `opening_book_entry`：首次进入开局库或完成一段熟悉变化

触发：本局前 8～12 个半回合内，当前局面仍命中开局库；同一局最多播放一次或两次。

1. `[从容，微笑]` 这一步很熟。你走进了准备好的路。
2. `[轻快]` 开局走得漂亮，至少前几页没有乱。
3. `[低声赞许]` 熟悉的结构。真正的较量还在后面。
4. `[优雅]` 第一段走得干净，别急着以为整盘都懂了。

### `opening_book_exit`：离开开局库后的第一手可靠选择

触发：上一局面命中开局库，本手成为第一手非库着；每局最多一次。

1. `[停顿后认真]` 库里的答案到这里，接下来才轮到你思考。
2. `[轻笑]` 熟悉的路走完了。现在，每一步都算你的。
3. `[戏剧停顿]` 理论结束。欢迎来到没有标答的地方。
4. `[平静]` 前面是准备，后面是棋力。

### `player_accurate`：玩家走出准确棋

触发：引擎判断为 `accurate`，且不是普通重复走子；同一局最多每 6 个半回合一次。

1. `[短促赞许]` 很准。你没有给局面留下多余的噪音。
2. `[柔和]` 这一步干净，像把门轻轻关上。
3. `[认真]` 几个候选里，你拿到了最稳的那个。
4. `[轻笑]` 没有炫技，只有准确。这样的棋最难对付。

### `player_best`：玩家走出最佳棋

触发：引擎最佳着，且不是开局库或普通强制着；同一局最多每 5 个半回合一次。

1. `[明显赞许]` 这就是答案。你找得比我想象中快。
2. `[有重量]` 漂亮，局面最窄的门，被你正好推开。
3. `[认真起来]` 这一手有分量。我得认真回应了。
4. `[克制赞赏]` 好棋。不是因为好看，是因为它真的解决了问题。

### `player_brilliant`：玩家走出妙手或计算深度很高的漂亮棋

触发：引擎判断为 `brilliant`，或确认弃子换取显著主动权；每局最多 2 次。

1. `[吸气，惊讶]` ……这一下，漂亮得有点过分。
2. `[兴奋但克制]` 你把一枚子放上祭坛，换来了整盘的主动。
3. `[轻笑，承认]` 好大胆。更难得的是，它是对的。
4. `[认真赞叹]` 这不是送子，是把棋盘的秩序重新洗牌。
5. `[压低声音]` 我得承认，这一手让我笑不出来了。

### `lia_best_move`：莉亚自己走出关键最佳棋

触发：莉亚的着法被引擎判定为 `best` 或 `great`，且形成明确威胁；不要每次最佳着都播。

1. `[从容]` 轮到我了。这个答案，我不会放过。
2. `[低声]` 看见了吗？最有力的那条路，通常不吵。
3. `[冷静]` 这一手不华丽，但它把几扇门都锁上了。
4. `[压力上升]` 压力回来了。现在请你找出同样准确的回应。

## 吃子与子力变化

吃子按价值分级。普通兵不必每次说；同类事件连续出现时优先保持安静。

### `capture_pawn`：莉亚吃掉玩家的兵

触发：吃兵且不是开启杀攻、升变或关键战术的核心一步；低频使用。

1. `[轻快]` 一兵落袋，别小看这种小账。
2. `[轻笑]` 小小一口，先把节奏咬住。
3. `[从容]` 这枚兵的位置太松了，我替你收拾。
4. `[平静]` 少一兵，故事还长；但账已经记下。

### `capture_minor`：莉亚吃掉玩家的马或象

触发：吃掉轻子，或完成交换并获得明确结构收益。

1. `[沉稳]` 轻子落下。这个交换可不轻。
2. `[低声]` 防线少了一根骨头。
3. `[满意]` 这一枚不是路过，是被我准确拿走。
4. `[严肃]` 少了一个轻子，接下来的每条线都会更窄。

### `capture_rook`：莉亚吃掉玩家的车

触发：吃车，或吃车后形成决定性优势。

1. `[惊喜后收住]` 车倒下，开放线归我了。
2. `[低沉]` 重子离场，局面的声音突然变大。
3. `[满足]` 这一车很值钱，我收得相当满意。
4. `[压迫]` 车没了。现在，谁来守住那条线？

### `capture_queen`：莉亚吃掉玩家的后

触发：吃后；每局不应连续使用多次，后续普通吃子静音。

1. `[停顿，惊叹]` 后没了……这下可不是小问题。
2. `[压低声音]` 我拿走你的后，棋盘突然安静了。
3. `[轻笑]` 这么贵重的礼物，叫我怎么拒绝？
4. `[从容收尾]` 后落袋。接下来请把残局下得体面些。

### `player_loses_minor`：玩家吃掉莉亚的马或象

触发：玩家吃掉莉亚的轻子，且不是莉亚主动的已知牺牲。

1. `[吸气后赞许]` 我的轻子没了。很好，你终于盯到了它。
2. `[认真]` 这一口吃得漂亮，我需要换一套计划。
3. `[短暂失落]` 一枚轻子而已？不，这里会留下回声。
4. `[克制]` 你拿得很准，局面换了重量。

### `player_loses_rook`：玩家吃掉莉亚的车

触发：玩家吃车，且不是简单回收交换；重要事件优先于普通棋力评价。

1. `[吸气，承认]` 车被你收走了。这个代价，我记住了。
2. `[严肃]` 重子离场，看来我得重新谈条件。
3. `[低声]` 你拿得很准，偏偏是最不该丢的那枚。
4. `[克制赞许]` 这笔交换不便宜。你赢得很实在。

### `player_loses_queen`：玩家吃掉莉亚的后

触发：玩家吃后；此事件优先级仅低于将杀结果。

1. `[明显惊讶]` 我的后……好吧，这确实值得庆祝。
2. `[停顿，认真]` 后被你拿走。终于轮到我承认局面变了。
3. `[低沉]` 这一口太重，我要把棋盘重新拼起来。
4. `[苦笑]` 你抓住了后。漂亮，别让这份礼物白拿。

## 战术与关键威胁

### `tactic_fork`：捉双

触发：确认玩家或莉亚的马、兵、后形成两个高价值目标的双捉；不要仅凭攻击两个子判断。

1. `[兴奋]` 一叉两吃。两件东西，只能保一件。
2. `[压低声音]` 这一跳很坏，两个目标同时收到通知。
3. `[轻笑]` 马把局面分成了两半，你算得很清楚。
4. `[强调]` 漂亮的双捉。现在轮到你挑一件留下。

### `tactic_pin`：牵制

触发：确认被牵制的棋子移动会导致王、后或车遭受直接重大损失。

1. `[低声]` 牵住了。前面的子一动，后面的麻烦就会露出来。
2. `[压迫]` 这条线把它钉住了，呼吸都得小心。
3. `[提醒]` 别急着动那枚子，它身后站着更贵的东西。
4. `[满足]` 牵制成立。局面开始替你施压。

### `tactic_discovered_attack`：发现攻击或揭示暗线

触发：移动前方棋子后，后方的车、象或后产生有效攻击。

1. `[揭幕感]` 你把前面的子移开，后面的线终于开口了。
2. `[低声兴奋]` 一道暗线醒了。棋盘比刚才锋利。
3. `[戏剧停顿]` 这不是移动，是揭幕。
4. `[迅速]` 后手的威胁，现在露面了。

### `tactic_zwischenzug`：中间手或强制插入手

触发：玩家在预期交换前插入将军、吃子或强制威胁，并得到明确收益。

1. `[惊讶]` 先别急着换。你在中间塞进了一句更重要的话。
2. `[赞许]` 这一下很细。真正的顺序，被你看见了。
3. `[轻笑]` 交换可以等，威胁不能。
4. `[认真]` 好的中间手，常常只差这一拍。

### `tactic_sacrifice`：弃子换攻、换时间或换结构

触发：确认玩家或莉亚主动牺牲子力，并获得显著补偿；禁止把单纯送子误报为弃子。

1. `[吸气]` 弃子？……不，你是在买时间。
2. `[兴奋]` 你交出物质，换回了主动权。很有胆量。
3. `[低沉赞许]` 这枚子不是丢的，是被你用来开门的。
4. `[满意]` 我喜欢这个代价。它换来的东西更值钱。

### `key_threat`：出现必须马上回应的强制威胁

触发：将杀威胁、重子悬挂、双重攻击或下一手不可逆威胁；不是普通攻击。

1. `[压低声音]` 我已经把问题摆到你面前了。
2. `[紧迫]` 这不是普通的威胁，下一拍会更难看。
3. `[倒计时感]` 看清楚，棋盘上有一处正在倒计时。
4. `[短促]` 现在轮到你决定，守哪一边。

## 王的安全与结局

### `check`：莉亚将军

触发：莉亚走出将军，且不是普通重复将军；强制战术优先。

1. `[短促有力]` 将军。请把注意力收回来。
2. `[压迫]` 王被叫住了，计划先暂停。
3. `[低声]` 这不是提醒，是必须回答的问题。
4. `[紧迫]` 将军落下，棋盘只给你几秒钟的选择。

### `player_check`：玩家将军莉亚

触发：玩家将军，且将军不是无效骚扰；普通将军低频播放。

1. `[意外后镇定]` 将军收到。很好，现在看你的后续。
2. `[认真]` 这一声有分量，我先处理王的安全。
3. `[轻笑]` 你把问题递过来了，我会原样还回去。
4. `[从容]` 王被你叫住一会儿，棋局还没有改判。

### `missed_mate`：玩家错过杀棋

触发：引擎确认玩家上一手存在强制将杀，且当前已经失去；每局最多一次。

1. `[遗憾，压低声音]` 等等，这里本来有将杀。你把结尾放走了。
2. `[惋惜]` 胜负的门开过一次，可惜你没有进去。
3. `[停顿]` 这一刻少了一拍，最锋利的刀就钝了。
4. `[克制提醒]` 杀棋擦肩而过。别让它影响你的下一步。

### `blunder_into_mate`：玩家走入必杀局面

触发：玩家上一手导致莉亚存在强制将杀；将杀播出前优先播一次，避免两句重叠。

1. `[吸气，低沉]` ……这一步，直接走进了结局。
2. `[压低声音]` 王自己走进了最后一扇门。
3. `[冷静但锋利]` 没有回头路了。这个漏洞太深。
4. `[戏剧收束]` 将杀已经写在这里，你只是替它落了笔。

### `mate`：完成将杀

触发：棋局结束；只播放一条，优先于所有吃子和评价。

1. `[低沉，收尾]` 将杀。王没有下一句了。
2. `[从容]` 结束。所有出口都已经关上。
3. `[戏剧停顿]` 这一幕到这里，确实没有续集。
4. `[轻声]` 将杀。你把最后一道门也关上了。

### `castling`：完成王车易位

触发：易位完成；每局最多一次，除非是关键防守。

1. `[舒展]` 王先安顿，车再说话。
2. `[从容]` 易位完成。安全感和进攻线一起到位。
3. `[满意]` 这次搬家很及时，王终于有了位置。
4. `[轻快]` 王车换位，下一幕可以开始了。

### `promotion`：升变

触发：完成升变；优先于普通吃子和普通最佳评价。

1. `[兴奋]` 升变。小兵终于拿到它应得的名字。
2. `[惊叹]` 走到尽头，棋子换了身份，威胁也换了形状。
3. `[抬高音调]` 新子登场。残局突然不再谦虚。
4. `[戏剧收束]` 升变完成。别眨眼，局面已经换频道。

## 失误、翻盘与防守

### `queen_early`：玩家过早出后

触发：开局阶段后出动过早，且引擎确认损失节奏或被有效追赶；不能只按回合数判断。

1. `[提醒，带一点笑]` 后出得很早。希望你已经替它安排好回程。
2. `[轻声]` 别急着让后单独工作，它会被棋盘追问。
3. `[观察]` 贵客提前登场，可惜全场都在盯着它。
4. `[锋利]` 出后太早，节奏先交了一半。

### `defense_found`：玩家找到唯一或关键防守

触发：玩家走出引擎最佳防守，避免明显损失；这是鼓励型关键语音。

1. `[松一口气]` 守住了。你没有被第一眼的威胁骗走。
2. `[赞许]` 好防守，最危险的地方被你封住了。
3. `[克制]` 这一手不抢戏，却救了整盘棋。
4. `[认真]` 你找到了唯一不崩的办法。

### `player_missed_tactic`：错过明显战术机会

触发：玩家错过双捉、牵制、串击或可兑现的重大收益，但没有达到错失杀棋。

1. `[遗憾]` 机会来过，只是停得太短。
2. `[轻叹]` 这条线本来可以更锋利。
3. `[提醒]` 你看见了棋子，没看见它们之间的关系。
4. `[从容]` 好的战术不会一直等人，下一次要快半拍。

### `comeback`：玩家从明显劣势中扳回局面

触发：玩家连续准确着法，使评估跨过预设翻盘阈值；同一局最多一次。

1. `[明显赞许]` 还没结束。你刚刚把棋盘拉回来了。
2. `[松一口气]` 这口气接得漂亮，劣势没有继续扩大。
3. `[认真]` 绝境里找到这一步，难得。现在重新开始。
4. `[轻笑]` 局面翻回来了。别浪费第二次机会。

## 制作与命名建议

以下为早期第一批规划。实际第一批为 60 条、18 类，现已补齐至完整 121 条、30 类；完整文件清单以制作单和 `ChessCoachResources/coach_lines.json` 为准：

`opening_book_entry`、`opening_book_exit`、`player_accurate`、`player_best`、`player_brilliant`、`capture_minor`、`capture_rook`、`capture_queen`、`player_loses_minor`、`tactic_fork`、`tactic_pin`、`tactic_sacrifice`、`missed_mate`、`blunder_into_mate`、`mate`。

文件名统一使用 `lia_<category>_<number>.m4a`，例如 `lia_player_brilliant_03.m4a`。每个文件旁边保留同名 JSON 元数据，记录正文、情绪、触发条件和录音版本，后续重录时不需要改 Swift 或 TypeScript 的映射。

MiniMax 制作时建议每组先生成 2～3 个候选，只保留停顿自然、句尾不塌、情绪不夸张的版本。录音完成后再统一做响度、静音头尾和 AAC 压缩处理；不要在文案里直接写「叹气」「轻笑」等括号，除非当前 API 明确支持这些控制标记。
