# Chessground 棋盘与棋子资源

来源：[`Dash1971/maia-chess-android`](https://github.com/Dash1971/maia-chess-android)，其资源来自 Flutter Chessground 的筛选资源包。

本项目新增并实际使用的资源：

- `boards/`：`wood2`、`wood3`、`wood4`、`maple`、`maple2`、`blue2`、`blue3`、`blue-marble`、`canvas2`、`leather`、`ncf-board`、`green-plastic`、`marble`、`grey`、`metal`、`olive`、`newspaper`、`purple-diag`、`pink-pyramid`、`horsey`。
- `pieces/pirouetti/`：Pirouetti，AGPL-3.0-or-later。
- `pieces/kosal/`：Kosal，AGPL-3.0-or-later。
- `pieces/firi/`：Firi，CC-BY-4.0。
- `pieces/governor/`：Governor，AGPL-3.0-or-later。
- `pieces/kiwen-suwi/`：Kiwen-suwi，CC-BY-4.0。

完整许可证正文保存在本目录。棋子文件保留上游 WebP 资源，不做转码或图像改造。
